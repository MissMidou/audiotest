# Contract: H5 目录页（Directory Page）

**适用对象**：前端静态页与构建脚本；测试/验收时据此验证行为与数据格式。

---

## 1. 清单数据契约（Manifest）

- **来源**：构建脚本生成的 `manifest.json`（或等价内联数据），置于可被前端请求到的路径（如与 `index.html` 同目录或约定路径）。
- **格式**：JSON；根对象包含数组字段 `items`。
- **单条 `items[]` 约定**：
  - `id` (string)：稳定唯一标识，用于 DOM 与播放切换。
  - `label` (string)：展示名称。
  - `url` (string)：相对或绝对音频 URL，可直接作为 `<audio src="...">` 的 `src`。
- **空列表**：`items` 为 `[]` 时，页面进入“空目录”状态，展示“暂无可播放音频”类文案，不渲染播放列表。

---

## 2. 页面行为契约

- **加载阶段**：
  - 进入页面后立即进入 loading 状态（可见 loading UI）。
  - 请求 manifest 或解析内联数据；成功则进入 ready，渲染列表；失败或超时（建议 10–15 秒）则进入 error，展示错误提示。
- **就绪阶段**：
  - 展示音频列表，每项可点击；点击后开始播放该曲目，并可视需要高亮当前项、展示播放/暂停控制。
- **播放**：
  - 同一时刻仅一首在播；切换曲目时停止当前、播放新选曲目。
  - 若某曲目加载/播放失败，可展示该曲目级别的错误提示，不导致整页白屏。
- **无障碍与兼容**：
  - 使用标准 HTML5 `<audio>`；不依赖未在 research 中采纳的第三方播放器或专有 API。

---

## 3. 验收对照

| Spec 要求 | 契约对应 |
|----------|----------|
| 页面显示音频目录/列表 | manifest.items 渲染为列表 |
| 用户可选择列表中任一项播放 | 点击 item 触发播放，url 作为 audio src |
| 加载中 loading、超时错误提示 | 加载阶段 loading；超时/失败 → error 状态与文案 |
| 目录为空时明确提示 | items 为空时展示“暂无可播放音频” |
| 列表与指定文件夹一致 | 由构建脚本保证：仅扫描指定文件夹并生成 manifest |
